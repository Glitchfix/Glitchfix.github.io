I'm Shivanjan Chakravorty.

I write software. Current interests: model inference, GPU simulation, and 3D reconstruction.
I was at NVIDIA on Omniverse, and before that in distributed storage at Pure Storage and
Portworx.

The code is on [GitHub](https://github.com/Glitchfix), the thinking is [here](/blog/). A
reasonable place to start is [Where the eight seconds were hiding](/blog/eight-seconds/).
